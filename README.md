# CppMiao - C++ 代码喵化工具

将你的 C++ 代码转换为"喵呜"语言的趣味转换器。

## 项目简介

MiaoCode 是一个独特的 C++ 源码转换工具，它能将普通的 C++ 程序转换为使用指定字符集（默认为"喵"和"呜"）编码的版本。转换后的代码在功能上与原始代码完全等效，但可读性会变得比较有趣。

这可以用作：
- 教学演示（词法分析、编码原理）
- 娱乐项目（分享"喵语言"代码）

## 功能特点

- **智能词法分析**：准确识别 C++ 代码中的标识符、运算符、字符串、注释等不同 token 类型
- **频率优化编码**：根据 token 出现频率自动分配最短编码，高频 token 使用更短的"喵呜"组合
- **保留格式**：完整保留原始代码的缩进和空白字符
- **自定义字符集**：支持使用任意字符作为编码基础（不仅限于"喵呜"）
- **注释与字符串保护**：正确处理注释和字符串字面量，避免误转换

## 快速开始

### 编译

```bash
make
```

这将生成可执行文件 `miao`。

### 基本用法

将 `example.cpp` 转换为默认的"喵呜"编码：

```bash
./miao -f example.cpp
```

程序会直接修改源文件，并在开头添加所有必要的 `#define` 宏定义。

### 自定义字符集

使用自定义关键词文件（关键词之间用空格、制表符或换行等空白字符分隔）：

```bash
./miao -k mykeywords.txt -f example.cpp
```

关键词文件示例（可用空白字符任意分隔）：
```
喵 呜
```

或

```
喵
呜
```

## 工作原理

1. **分词**：程序对 C++ 源码进行分析，分离出宏和注释，识别出需要编码的 token
2. **频率统计**：统计每个 token 的出现次数
3. **编码分配**：根据频率分配编码，高频 token 获得更短的编码
4. **进制转换**：将 token ID 转换为以关键词数量为基底的进位制表示
5. **代码生成**：生成 `#define` 宏定义和编码后的代码

默认关键词 `["喵", "呜"]` 相当于二进制，你可以添加更多关键词实现更高进制（更短编码）。

## 示例

原始代码 `C.cpp`：
```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    printf("Hello World");
    return 0;
}
```

转换后效果（示意）：
```cpp
#define 喵 ;
#define 呜 (
#define 喵喵 )
#define 呜喵 "Hello World"
#define 喵呜 0
#define 呜呜 int
#define 喵喵喵 main
#define 呜喵喵 namespace
#define 喵呜喵 printf
#define 呜呜喵 return
#define 喵喵呜 std
#define 呜喵呜 using
#define 喵呜呜 {
#define 呜呜呜 }
#include<bits/stdc++.h>
呜喵呜 呜喵喵 喵喵呜 喵
呜呜 喵喵喵 呜 喵喵 喵呜呜
    喵呜喵 呜 呜喵 喵喵 喵
    呜呜喵 喵呜 喵
呜呜呜
```

## 注意事项

- **备份重要代码**：程序会直接修改源文件，请确保已备份
- **编译测试**：转换后的代码需要重新编译测试
- **调试困难**：编码后代码极难调试，建议保留原始代码

## 构建配置

编译器要求：支持 C++17 的编译器（g++ 7+ 或 clang++ 5+）
